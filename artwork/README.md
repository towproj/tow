# tow artwork

The tow otter. Sea otters hold paws while they sleep so the group doesn't drift apart; tow keeps a cluster together the same way.

| File | Use |
|---|---|
| `tow-horizontal-light.svg`, `tow-horizontal-dark.svg` | otter and name side by side, for light and dark backgrounds |
| `tow-stacked-light.svg`, `tow-stacked-dark.svg` | otter above the name, for square spaces |
| `tow-icon.svg` | the otter alone, for light backgrounds |
| `tow-icon-dark.svg` | the otter alone with a light edge, for dark backgrounds (the docs site navbar) |
| `tow-favicon.svg`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon-180.png` | a simpler otter for 32 px and below |
| `tow-avatar.svg`, `tow-avatar-500.png` | GitHub organization avatar |
| `tow-social.svg`, `tow-social-1280x640.png` | GitHub social preview |

Colors: navy `#13233a`, otter brown `#8a5a3c`, rope red-orange `#e4572e`.

The name is set in [Sora](https://github.com/sora-xor/sora-font) ExtraBold (SIL Open Font License 1.1), turned into outlines, so the files need no font.
