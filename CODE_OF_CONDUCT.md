# Code of Conduct

tow follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Everyone who takes part in the project, in issues, pull requests, discussions and any other place it gathers, is expected to follow it.

## Reporting
Report unacceptable behavior to the maintainers at **thetowproj@gmail.com**. Reports are kept confidential, and the maintainers will answer within 7 days. A report about a maintainer can go to the other maintainers only, once there are several.
